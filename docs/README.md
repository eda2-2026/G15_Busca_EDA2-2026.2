# Documentação

Esta pasta tem como objetivo **centralizar e registrar toda a pesquisa realizada durante o desenvolvimento do algoritmo de busca**.

A documentação busca facilitar a compreensão do processo de desenvolvimento, reunindo informações sobre as pesquisas, decisões tomadas, conceitos utilizados, implementação e demais aspectos relevantes do projeto.

Dessa forma, quem tiver acesso ao projeto poderá **entender como o algoritmo foi desenvolvido, consultar as referências utilizadas e reproduzir sua execução** de maneira mais clara e organizada.
