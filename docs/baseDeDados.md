# Base de Dados

Nossa base de dados é composta por informações sobre **filmes brasileiros e estrangeiros exibidos entre 2009 e 2019**.

Os dados estão organizados em **9 colunas**, que apresentam diferentes informações sobre cada obra:

* **Ano de exibição**
* **Título da obra**
* **Gênero**
* **País(es) produtor(es) da obra**
* **Nacionalidade da obra**
* **Empresa distribuidora**
* **Origem da empresa distribuidora**
* **Público no ano de exibição**
* **Renda (R$) no ano de exibição**

A base foi obtida em formato `.csv` através do [Kaggle](https://www.kaggle.com/datasets/pedrothiago/anlise-dos-filmes-exibidos-2009-a-2019) e já possui os dados tratados. Para facilitar o acesso e manter os dados utilizados no projeto centralizados no repositório, o arquivo está disponível em [`filmes.csv`](../filmes.csv).

O objetivo do projeto é utilizar essas informações como base para a implementação de um **algoritmo de busca**, permitindo realizar consultas e localizar dados relevantes sobre os filmes presentes na base.

Conforme o desenvolvimento do algoritmo avançar, serão avaliadas e selecionadas as informações mais relevantes para o contexto da aplicação. Dessa forma, **apenas uma parte dos dados originais poderá ser utilizada na implementação final**, de acordo com os critérios e necessidades definidos para o algoritmo de busca.
